## The pipeline
1. **Replays:** IL_Replay, 252,238 games (`~/cr-engine/data/IL_Replay/replays/part-*.parquet`, 5,000 a file). Moves
   only: tick (when the card landed), side, card, position; decks; final tower HP. No board.
2. **Version oracle:** replay each game in the engine; keep it only if all six towers end exactly as recorded (~69.5%).
3. **Convert:** replay kept games again and save the full raw record every 5 ticks (~140 kB a game).
4. **Features:** built on the fly by train.py (PlayerView). A play landing at tick c is labelled at the last decision
   before c-22, so self-play must land plays 23-27 ticks after the decision (`il.data.PLAY_DELAY`, drawn per play).
5. **Pilot:** 20k games, 6 ablations. Then the full IL run with the winning setup.
6. **Later:** port PPO (il/rl.py, il/actors.py) to clapha-il features, then General PPO, judged by a fixed-panel arena.
